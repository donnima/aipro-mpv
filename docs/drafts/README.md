# Drafts (non-authoritative)

Files in this directory are **drafts**. They are not instructions for automated
task execution.

- Do not list paths under `docs/drafts/` as **Active Task**, **Authoritative Review**,
  or other instruction fields in `docs/status/CURRENT_STATUS.md`.
- Prefer `*.draft.md` naming for unfinished reviews and handoffs.
- Promote to `docs/reviews/`, `docs/handoffs/`, or `docs/tasks/` only when the
  authoring agent delivers and commits under its write lock.

See `docs/process/AGENT-WORKFLOW.md`.
